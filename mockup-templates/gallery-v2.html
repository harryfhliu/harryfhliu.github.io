「如是我闻」风格对比 · 第二批方案

4 套全新风格，气质差异更大：浅色 / 深色、东方 / 西方、古典 / 未来都有覆盖。每个框内可独立滚动、悬停看交互动效。

方案 A · 墨韵东方新中式 · 浅色
最契合「如是我闻」
宣纸米白底 + 墨黑文字 + 朱砂印章 + 宋体/楷体。大量留白，站名配篆刻印章落款，气质最接近佛经的「古雅庄重」。
方案 B · 装饰艺术Art Deco · 深色
几何奢华
深黑底 + 香槟金 + 放射状太阳纹 + 对称布局 + 几何边框。20 年代纽约/上海滩的奢华几何感，比「黑金奢华」更强调对称与装饰纹样。
方案 C · 瑞士国际主义Swiss · 浅色
极简克制
纯白底 + 严格网格 + 红黑强调 + 无衬线大字。功能主义、冷静理性，信息密度高、可读性最好，最像「档案/知识库」。
方案 D · 赛博朋克Neon · 深色
未来科技感
深黑蓝底 + 霓虹青/品红发光 + 网格扫描线 + 等宽字体。视觉冲击最强、最有「未来感」，但和「如是我闻」的古雅气质反差最大。
