# 如是我闻

个人知识库与博客，站名取自佛经开卷语「如是我闻」（Evaṃ mayā śrutam，意为「我是这样听闻的」）。

## 内容

- 小说创作
- 诗歌
- 技术调研（分布式光纤传感、测井技术、新能源、地质探测等）

## 技术栈

- 框架：[Astro](https://astro.build) 6
- 部署：GitHub Pages，自定义域名 `harryliu.cn`

## 分支说明

- `master`：构建产物，GitHub Pages 发布源
- `source`：Astro 源码（待推送）
- `jekyll-source`：旧 Jekyll 源码备份（回滚用）

## 本地开发

```bash
npm install
npm run dev      # 本地预览
npm run build    # 构建到 dist/
```
